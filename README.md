# 3D Pyramid & Cube - OpenGL ES

An Android application demonstrating real-time 3D rendering using OpenGL ES 3.2 and GLSL.

## Technologies Used

- Java
- C++
- Android
- OpenGL ES 3.2
- GLSL
- Android Studio
- Gradle

## Features

- 3D Pyramid rendering
- 3D Cube rendering
- Real-time OpenGL ES rendering
- Vertex and Fragment Shaders
- 3D transformations
- Android touch/input handling

## Project Structure

- `MainActivity.java` - Main Android activity
- `GLESView.java` - OpenGL rendering and touch handling
- `MyAttributes.java` - OpenGL attribute management
- `3D_PCNT.cpp` - Native C++ component

## Purpose

This project was developed to gain hands-on experience in Android graphics programming, OpenGL ES, GLSL shaders, and real-time 3D rendering.
